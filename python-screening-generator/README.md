# Team-contributed screening question generator

This module was contributed by Group 8 teammates as part of the TechCrush AI Automation capstone. Grace Omolola Odukoya was the team lead and integration coordinator. This module's Python implementation should not be represented as her individual code.

The historical source uses LangChain, Gemini and Pydantic to generate eight questions across distinct competencies. It contains a hardcoded fictional candidate example. The exact model identifier and dependencies may need updating to match currently available provider versions.

Install dependencies in a virtual environment, configure `GOOGLE_API_KEY` in a **private** environment, then run `python main.py` with fictional input only. Verify your API access, response shape, costs and privacy controls before running it against real data. Successful live inference has not been independently verified as part of this GitHub publication.
